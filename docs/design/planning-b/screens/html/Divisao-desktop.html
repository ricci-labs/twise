Divisão da comissão

Quando entra uma renda variável, o app sugere para onde vai cada parte, nesta ordem.

Passos, nesta ordem

Arraste pela alça ou use o ⋯ para mudar a ordem. Até 10 passos.

  1. Passo 1R$ 600,00 para a PoupançaValor fixo · a reserva de emergência
  2. Passo 2Cobrir o que passou do orçamentoNeste período: Lazer passou R$ 60,00
  3. Passo 320% para a Conta ViagemPorcentagem da comissão inteira · meta Viagem para o Chile
  4. Passo 4O que sobrar para a Conta XSempre o último passo
  • Os passos de cima recebem primeiro; se a comissão acabar, os de baixo ficam sem.
  • Porcentagem é sempre da comissão inteira, não do que sobra.
  • “O que sobrar” é sempre o último e só pode haver um.
