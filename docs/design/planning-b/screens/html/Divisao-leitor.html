Divisão da comissão

Quando entra uma renda variável (a comissão), o app sugere para onde vai cada parte, nesta ordem. Os passos de cima vêm primeiro.

  1. Passo 1R$ 600,00 para a PoupançaValor fixo · a reserva de emergência
  2. Passo 2Cobrir o que passou do orçamentoNeste período: Lazer passou R$ 60,00
  3. Passo 320% para a Conta ViagemPorcentagem da comissão inteira · meta Viagem para o Chile
  4. Passo 4O que sobrar para a Conta XSempre o último passo
