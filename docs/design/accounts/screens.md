# Accounts, categories and cards screens

65 boards. Fictitious numbers that match the Home: Conta X R$ 4.200,00, Conta Y R$ 2.800,00, Poupança R$ 12.000,00, Cartão X closes on the 25th and is due on the 4th, November invoice R$ 1.950,00 (R$ 240,00 from contacts). Notes are in pt-BR, as written by the designer; the copy in the screens is final. A note that starts with "PROPOSTA" depends on an API change (`decisions.md`).
