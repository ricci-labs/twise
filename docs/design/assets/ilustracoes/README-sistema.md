# System illustrations

Drawn in the same style as the category illustrations (perfect-freehand strokes, ink outline, mint fill). Paper version here (`fatura-paga.svg`, `transferencia.svg`, `saldo-inicial.svg`, `recebimento.svg`); loose version in `soltas/` with the same names. Rules as in `soltas/README.md`.

| File | Use |
|---|---|
| `fatura-paga` | Invoice payment (the "Pagamento" line of an invoice, "Pagamento de fatura" in "Mais") |
| `transferencia` | Transfers between accounts |
| `saldo-inicial` | Opening balance |
| `recebimento` | A contact paying back ("Recebimento de contato") |
