# Illustrations without the paper square

Same drawings as `../` with the `#efebe0` rounded square removed. Rule (decided in the ENT-02 round, applies to the whole app, Home included):

- **Never clip an illustration in a circle** (it cut the details at the corners).
- On a white or light surface (picker fields, list rows, sheets, the invoice preview, banners, cards) use these loose versions, 42–46 px (the drawing fills about 70% of its box, so it needs a little more size than the old 36 px circle).
- The paper square (the files in `../`) is used only when the illustration *is* the button, as in the category grid: paper tile when not selected; selected = the whole tile `--mint`, label bold, a dark check in the corner.
